# Screenshot Placeholders

The website is wired for these drop-in images. Replace the placeholder CSS
frames by adding PNG files with these exact names; no HTML path changes should
be needed.

| File | Purpose | Suggested size |
|---|---|---:|
| `home.png` | Hero and OpenGraph/Twitter image | `1290 x 2796` |
| `gameplay.png` | Main gameplay screenshot | `1290 x 2796` |
| `daily-leaderboard.png` | Daily leaderboard screenshot | `1290 x 2796` |
| `stats.png` | Stats screen screenshot | `1290 x 2796` |
| `share-card.png` | Optional share/social preview | `1200 x 630` |

Export screenshots without private test data, raw Firebase IDs, Support IDs,
or unreleased App Store links.
